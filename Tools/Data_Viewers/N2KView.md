# N2KView
**Note: this software only works on Maretron products**
## Summary
This is a software that allows investigators to interface directly with the vessel's Local Area Network using the Internet Protocol Gateway device. It provides a graphical interface to view current status of all equipment and even NMEA device messages.

## Requirements
Internet Protocol Device

This may be found anywhere on the ship, likely on the bridge.

## Download
https://www.maretron.com/products/n2kview-vessel-monitoring-and-control-software/

To create the NMEA 2000 LAN connection: **Commands & Settings** > **Configuration** > **NMEA 2000 Connection**

To view active NMEA messages on the vessel: **Commands & Settings** > **About** > **Diagnostics**
