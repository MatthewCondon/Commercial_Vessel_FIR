The document below details additional NMEA resources and cyberattack test features.

# canboat
Many of the tools and research was developed using the canboat repository. This GitHub contains resources designed for testing and researching vessel networks including NMEA. There are additional tools that may be found in the repository.

**canboat**: https://github.com/canboat/canboat

# MarCANex
When conducting initial research into the CAN protocol, attacks focused on individual PGN's were used to develop initial TTPs. These attacks were used to understand NMEA behavior during a possible cyberattack.

**MarCANex**: https://github.com/Jstith/MarCANex

# NEMO
After developing an understanding the relationship between NMEA and possible cyberattacks, more aggressive tests were used to strengthen the incident response scripts. This assisted with testing heavier attacks that were harder to detect such as a DOS.

**NEMO**: https://github.com/Soups71/NEMO
