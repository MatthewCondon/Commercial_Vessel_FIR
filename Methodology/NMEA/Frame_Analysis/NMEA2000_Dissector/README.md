# Summary
If you are dealing with NMEA 2000, you can configure Wireshark to automatically convert it to raw CAN data while also decoding into a human-readable format.

This zip file does not need to be located in any specific folder, and will automatically update your Wireshark profile configurations. First, download ```Maritime-N2K.zip```. Then, in Wireshark, go to:
```
Edit > Configuration Profiles > Import > From Zip File...
```
